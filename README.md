A furious one-paragraph rant about the self-checkout machine screaming
"UNEXPECTED ITEM IN THE BAGGING AREA" over a single, honestly scanned banana:
the flashing red light, the public shaming, the teenager with the secret
forgiveness code, and the punchline — you work there now, unpaid, and you are
already suspected of theft.

Competition: https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046

## Run

```sh
python3 main.py
```

Writes the rant (303 characters, UTF-8) to `/output/entry.txt`.
Pure Python standard library, deterministic — same bytes on every run.
